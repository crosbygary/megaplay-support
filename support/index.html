Quick answers

How do I make my first game?

Open Create, choose a genre, and customize the template in Workshop. Tap Save game, then Play game to try it. Editing a saved game changes the button back to Save game.

How do I share a creation?

Use Export game to save a .megagame project. Another MegaPlay user can import it to edit or play. This file is a MegaPlay project, not a standalone app.

How do I import a classic?

Open Classics and tap Import a game, or the + beside search. Read the ownership notice, choose the system, and select a compatible file in Files. Import only files you have the right to use.

Why does an imported game not start?

Compatibility and performance vary by game and device. PS1 and PS2 playback is experimental. Check the selected system and file format. Contact support with the format and error message; do not attach the game itself.

Where are my games stored?

Projects and imported copies are stored on your device. Export important projects before deleting the app. Deleting an imported game in MegaPlay removes its local copy and saves, not the original file you selected in Files.
